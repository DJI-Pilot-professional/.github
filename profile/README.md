## What is DJI Pilot

**DJI Pilot** is a professional-grade mobile application designed for **DJI Enterprise** drones such as **Matrice 300 RTK, Mavic 2 Enterprise, Phantom 4 RTK, and Matrice 30**.  
It provides pilots and engineers with powerful mission planning, telemetry visualization, diagnostics, and real-time data management.  
Ideal for inspection, mapping, rescue operations, and aerial surveying — DJI Pilot combines automation, precision, and safety in one app.

---

## Key Features

- 🚁 Full control of DJI Enterprise drones with RTK/PPK support.  
- 🗺 Mission planning tools: Waypoints, Area Scan, Mapping, and Grid flights.  
- 🧭 Real-time RTK accuracy with centimeter-level precision.  
- 📷 Support for Zenmuse cameras (XT2, Z30, H20, L1, P1).  
- 📊 Live telemetry and aircraft status dashboards.  
- 🛰 Offline map caching and flight history tracking.  
- 🧩 Integration with DJI Terra, FlightHub, and SDK.  
- 💾 Auto-save and cloud backup of flight logs and missions.

## Quick Start

1. Install **DJI Pilot** from the official DJI website.  
2. Connect your drone via OcuSync or USB.  
3. Sign in to your DJI Account and configure RTK.  
4. Create a new mission and plan your flight path.  
5. Export logs or synchronize with DJI Terra.
